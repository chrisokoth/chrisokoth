## About

I am a software engineer and data scientist working at the intersection of backend engineering, data engineering, and applied analytics. I design systems that are reliable under real load, observable in production, and simple enough for teams to maintain and extend.

My background spans engineering leadership, API and platform development, and quantitative modelling — which means I care as much about how a system is deployed and monitored as I do about the code and the models inside it.

## Engineering Principles

> **Production is the standard.** Software is finished when it runs reliably for real users, not when it runs locally.
>
> **Architecture is a long-term decision.** Clear boundaries and simple designs outlast clever ones.
>
> **Impact is measured.** Performance, reliability, and business outcomes are tracked, not assumed.
